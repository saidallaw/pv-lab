# Siraj PV Lab

Free, browser-based simulator that models solar PV modules **cell by cell** using real datasheets:
Jinko Tiger Neo (N-type TOPCon), Huasun Himalaya (HJT) and First Solar Series 6 (CdTe thin film).

**Open it:** https://saidallaw.github.io/pv-lab/

## What you can do
- Shade any cell, or add cracks, shunts and high series resistance, and watch V, I and P on live meters
- See hot spots form and bypass diodes switch on
- Compare half-cut and full-cell layouts under the same shadow
- Change ambient temperature, irradiance, location, month, time of day, tilt and azimuth
- Get daily and annual clear-sky yield and the best tilt for a location
- Build strings in series and parallel, see mismatch losses and multiple MPPT peaks, and check string sizing against an inverter MPPT window
- Upload any module datasheet (PDF) and simulate it

Educational model, not a substitute for PVsyst.
